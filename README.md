# Ranvex Web

Frontend application for Ranvex.

The current implementation is foundation-only and intentionally contains no
business feature. Application bootstrap, providers, routing, layouts, and
runtime configuration live under `src/app`. Business domains will be added
under `src/features`; shared components and utilities remain business-agnostic.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for dependency rules and
future feature boundaries.
