# Citra Negara LMS Web

Frontend application for Citra Negara LMS, built with Next.js App Router.

The current implementation is foundation-only and intentionally contains no
business feature. Next routes, layouts, metadata, and route-level boundaries
live under `src/app`; product domains will be added under `src/features`.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for dependency rules,
server/client component boundaries, and future feature structure.
